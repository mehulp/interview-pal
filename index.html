        Test it
        
      
        Sends one tiny request to Anthropic to check that the key and model work. It costs a fraction of a cent.
        
      
      
        

      
        
        Anyone who can open this browser profile can read the saved key, so do not use a shared computer.
        You can also set a monthly spend limit for the key in the Anthropic Console.
